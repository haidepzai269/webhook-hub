## Chạy thật trên Postgres (M-3)

1. **psql**, user `hub_user`, db `webhook_hub` (lấy từ `docker-compose.yml`), trong `BEGIN … ROLLBACK`: chèn `DH1234567` (PENDING/payos) và `DH9876543210` (EXPIRED/sepay); `PREPARE q(text[]) … = ANY($1) FOR UPDATE`.
   - `['DH1200000','DH1234567']` → `DH1234567` (tiền tố lạ bị loại, mã thật được chọn)
   - `['DH0000001']` → 0 dòng
   - hai mã đều có → 2 dòng
   - `EXPLAIN`: `LockRows → Index Scan using orders_order_code_key`, `Index Cond: order_code = ANY('{…}'::text[])` (dùng index unique)
   - Sau ROLLBACK đếm lại: 0 dòng
2. **Prisma `$queryRaw` tagged template với mảng JS**, user **`shop_user`** (đúng role của Shop, nên cũng chứng minh role có quyền khoá `FOR UPDATE`). Script nằm ở scratchpad, `$transaction` ném lỗi để rollback:
   ```
   {"prefixThenReal":[{"order_code":"DH7654321"}],"none":[],"both":[{"order_code":"DH7654321"},{"order_code":"DH1111111111"}],"injection":[],"afterRollback":0}
   ```
   Prisma gửi mảng JS thành **một tham số `text[]`**, không nội suy chuỗi. Phần tử chứa `' OR '1'='1` trả 0 dòng.
